# CLAUDE.md — 勤怠・給与・労務システム（株式会社ニジ看護転職）

このリポジトリは、人事労務freeeのような**勤怠・給与計算・労務手続き管理のWebアプリ**です。
Googleスプレッドシート＋Google Apps Script（GAS）で動き、サーバー代はかかりません。
**最初に `docs/SPEC.md`（仕様書）を読んでから作業してください。**

## 前提
- 利用者：総務・経理の担当者（管理画面）と従業員（マイページ）。どちらもITに詳しくない前提で、画面・メッセージ・説明はすべて日本語でわかりやすく書く
- 会社：株式会社ニジ看護転職（有料職業紹介業、従業員10名前後、拠点：五反田・赤坂・リモート、インセンティブ・固定残業代あり）
- データの保存先：会社のGoogleドライブ上のスプレッドシート（シートごとに「従業員」「勤怠」「給与」など）
- 届出書類の作成・提出は**会社の社員が自社の分を行う**。報酬を得て他社の届出を代行する機能・運用は作らない（社会保険労務士法27条）
- マイナンバーは保持しない

## フォルダ構成
```
roumu/                    計算ロジック（純粋関数・Node.jsでテスト）
  src/lib/*.js              勤怠・給与・源泉税・標準報酬・有給・労務手続き・賞与・年末調整・全銀振込・届出書類
  test/*.test.js            計算ロジックのテスト
roumu-sheets/             Googleスプレッドシート＋Apps Script版（本体）
  src/Code.js               シート入出力・メニュー・給与計算・タスク・通知など
  src/WebApp.js             Webアプリのサーバー側（api() だけを画面から呼ぶ）
  src/app.html              Webアプリの画面（従業員マイページ・管理画面）
  scripts/build.js          上記と roumu/src/lib を 1ファイル dist/Code.gs にまとめる
  dist/Code.gs              ★Apps Script に貼り付けるファイル（生成物・直接編集しない）
  test/                     GASのモック上でのフローテスト
  CLAUDE.md / README.md     GAS版の詳しい説明と導入手順
docs/SPEC.md              仕様書（機能・計算ルール・データ・未確認事項・今後の予定）
docs/FIRST_PROMPT.md      最初にClaude Codeへ伝える依頼文の例
```

## コマンド
```bash
npm test          # 計算ロジック＋GAS版のテストをすべて実行
npm run build     # roumu-sheets/dist/Code.gs を生成
```
Node.js 20以上。外部パッケージは不要。

## 作業ルール
- 計算の修正は `roumu/src/lib` で行い、`roumu/test` にテストを追加する。給与の結果が変わる修正は、変更前後の差額を説明できるようにする
- 画面・サーバーの修正は `roumu-sheets/src` で行い、`roumu-sheets/test` にテストを追加する
- 変更後は必ず `npm test` → `npm run build` を実行し、`dist/Code.gs` も一緒にコミットする
- 利用者への反映手順：`dist/Code.gs` を Apps Script に貼り直して保存 → 「デプロイ → デプロイを管理 → 鉛筆 → 新バージョン → デプロイ」（URLは変わらない）
- 金額は円の整数。社会保険料の本人負担は「50銭以下切捨て・50銭超切上げ」。浮動小数で端数判定しない
- 勤怠月（ym）と支給月（pay_ym）を区別する
- 確定済みの給与・賞与は再計算で上書きしない。重要な操作は操作ログに残す
- 料率・税額表など**公的な数値を変えるときは出典（国税庁・協会けんぽ・厚生労働省の資料名と年分）をコメントに残す**。確認できない値を推測で入れない
- ID・パスワード・APIキーなどの秘密情報はコードやチャットに書かない（Apps Scriptの「スクリプト プロパティ」に保存する）
