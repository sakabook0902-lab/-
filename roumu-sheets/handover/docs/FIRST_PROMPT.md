# Claude Codeへの最初の依頼文（例）

このリポジトリをClaude Codeで開いたら、最初に次の文章をそのまま貼り付けてください。

---

このリポジトリは、当社（株式会社ニジ看護転職）の勤怠・給与・労務システムです。
別のClaude Codeセッションで作られたものを引き継いでいます。

1. `CLAUDE.md` と `docs/SPEC.md` を読んで、システムの構成・計算ルール・未確認事項を把握してください。
2. `npm test` を実行して、すべてのテストが通ることを確認してください。
3. `npm run build` で `roumu-sheets/dist/Code.gs` を生成してください。
4. 当社のGoogleスプレッドシートに導入する手順を、ITに詳しくない総務担当者にもわかるように日本語で案内してください。
5. 把握した内容と、本番運用の前に確認が必要な事項（`docs/SPEC.md` の「未確認・要確認の事項」）を、日本語で短くまとめて報告してください。

説明はすべて日本語でお願いします。
