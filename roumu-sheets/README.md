# 勤怠・給与計算・労務手続き管理（Googleスプレッドシート版）

Googleスプレッドシートだけで動く、勤怠・給与計算・労務手続き管理のしくみです。**サーバー代はかかりません。**

- **従業員**：スマホで打刻用URLを開いて打刻（会社のGoogleアカウントでログインしていれば本人確認は自動、PIN不要）
- **総務**：スプレッドシートを開き、上部の「**労務**」メニューから給与計算・確定・明細作成
- **自動化**：毎朝、期限が近い労務手続き・36協定・有給の年5日・打刻漏れをメール／Slackでお知らせ

計算ロジックはサーバー版（`../roumu`）と共通で、`scripts/build.js` が1つのファイル `dist/Code.gs` にまとめています。

## できること

| 分野 | 内容 |
|---|---|
| 打刻 | 出勤・退勤・休憩開始・休憩終了、勤務場所（五反田／赤坂／リモート）。日付をまたぐ勤務にも対応。打刻画面で本人の今月の勤務時間・有給残日数も確認できる |
| 勤怠 | 時間外（1日8時間超＋週40時間超）・深夜・法定休日を自動計算。36協定の月上限・法定上限をチェック |
| 有給 | 法定の付与日数・残日数（2年で時効）・年5日取得義務を自動管理 |
| 給与計算 | 固定残業代の超過分、インセンティブ（歩合給）の割増、社会保険・雇用保険・源泉所得税・住民税。確定後は再計算で上書きしない |
| 給与明細 | PDFを自動作成してGoogleドライブに保存。同意した従業員にはメールで送信 |
| 労務手続き | 入社・退職・年次（算定基礎・年度更新・年末調整・法定調書・住民税・36協定更新）の手続きを期限付きで「労務タスク」に自動作成 |
| 月額変更届 | 従業員シートで基本給などを変えると自動で検知し、3ヶ月分の給与確定後に届出の要否を判定 |
| 証跡 | 勤怠・従業員・設定などをシート上で直接直した場合も「操作ログ」に記録 |
| 法定三帳簿 | 「従業員」＝労働者名簿、「勤怠」＝出勤簿、「給与」＝賃金台帳 として使える |

## 導入手順（30分ほど）

### 1. スプレッドシートを作ってプログラムを貼り付ける
1. Googleドライブで **新規 → Googleスプレッドシート** を作り、名前を「勤怠・給与・労務」などにします。
2. メニューの **拡張機能 → Apps Script** を開きます。
3. 最初からある `コード.gs` の中身をすべて消し、このフォルダの **`dist/Code.gs` の中身をすべて貼り付けて** 保存（Ctrl+S）します。
4. 左の歯車「**プロジェクトの設定**」で、**タイムゾーンを「(GMT+09:00) 日本標準時 - 東京」** にします。

### 2. 初期設定
1. スプレッドシートのタブに戻り、ページを再読み込みします。上部に「**労務**」メニューが出ます。
2. **労務 → 初期設定（シート作成）** を実行します。
3. 初回は権限の確認画面が出ます。「権限を確認」→ 自分のアカウントを選択 →「このアプリはGoogleで確認されていません」と出たら「詳細」→「（プロジェクト名）に移動」→「許可」を押します（自分で作ったプログラムなので問題ありません）。
4. もう一度 **初期設定** を実行すると、シートが作られます。

### 3. 設定と従業員の登録
1. 「**設定**」シートで、**【要確認】** の料率を協会けんぽ・厚生労働省の公式資料で確認し、通知先メールアドレスを入れます。
2. 「**従業員**」シートに1人1行で入力します。
   - **Googleアカウント（メール）**：会社のGoogleアカウント。これが入っていれば打刻時にPINは不要です
   - **打刻PIN**：4〜8桁の数字（先頭が0の番号は避ける）。Googleアカウントで確認できない場合に使います
   - **社会保険加入・雇用保険加入・明細メール配信の同意**：`TRUE` / `FALSE`
   - **標準報酬月額**：資格取得届・算定基礎届などの決定通知書の金額
   - **住民税**：毎年5月に届く「特別徴収税額決定通知書」の金額
3. 動作確認だけしたい場合は、**労務 → デモデータを投入** で架空の3名分のデータが入ります。

### 4. 打刻用URLを公開する
1. Apps Script の画面右上 **デプロイ → 新しいデプロイ** を押します。
2. 種類の選択（歯車）で **ウェブアプリ** を選びます。
3. **次のユーザーとして実行：自分**、**アクセスできるユーザー：（会社名）内の全員** を選んで「デプロイ」します。
   - 会社がGoogle Workspaceを使っていない（@gmail.com 等）場合は「Googleアカウントを持つ全員」を選び、従業員はPINで打刻します。
4. 表示された **ウェブアプリのURL** が打刻用URLです（あとから **労務 → 打刻用URLを表示** でも確認できます）。従業員に案内し、スマホの「ホーム画面に追加」をしてもらいます。

### 5. 毎朝のお知らせを設定する
**労務 → 毎朝の自動更新・通知を設定** を実行します。毎朝8時台にダッシュボードと労務タスクが更新され、お知らせがあれば通知されます。**通知のテスト送信** で届くか確認できます。

## 毎月の運用

1. 月初：「勤怠」シートで前月の打刻漏れを修正（ダッシュボードに出ます）
2. **労務 → ① 給与を計算**（前月を指定）→「給与入力」シートにインセンティブ・欠勤日数を入力 → もう一度 ① を実行
3. 「給与」シートで内容を確認（「要確認事項」列も見る）→ **② 給与を確定**
4. **③ 給与明細PDFを作成** →（同意者には）**④ 給与明細をメール送信**
5. 「労務タスク」シートで期限の近い手続きを処理し、「状態」を「完了」にする

---

## ⚠ 大事な注意

1. **共有範囲**：このスプレッドシートには全員の給与が入っています。**共有は総務・経理の担当者だけ**にしてください。従業員は打刻用URL（Webアプリ）だけを使います（プログラムはオーナーの権限で動くため、共有しなくても打刻できます）。
2. **料率・源泉所得税の確認**：初期値は令和8年度の公表情報をもとにした仮の値です。健康保険料率（東京）と源泉所得税の計算式は公式資料との照合が済んでいません。本番前に必ず確認し、2〜3ヶ月は既存の方法と並行して計算してください。
3. **シートの直接編集**：「給与」「操作ログ」シートは誤って編集しないよう保護（警告表示）しています。列の見出し名は変えないでください（見出し名で列を見分けています。列の並び替え・追加は問題ありません）。
4. **社労士法**：届出の作成・提出は自社の担当者または顧問社労士が行ってください。本システムは手続きの要否と期限の管理までです。
5. **マイナンバー**は入力しないでください。

## プログラムを更新するとき
1. `dist/Code.gs` の中身を Apps Script に貼り直して保存します。
2. 打刻画面に反映するには **デプロイ → デプロイを管理 → 鉛筆アイコン → バージョン「新バージョン」→ デプロイ**（URLは変わりません）。

## ニジ看護転職のアカウントへ引っ越す

スプレッドシートを**コピーするだけで、プログラムもデータも一緒に移ります**。

1. 自分のアカウントで動作確認が終わったら、本番前に **労務 → データをすべて消去**（デモデータを使った場合）。
2. スプレッドシートを、客先の管理者（総務責任者など）の会社アカウントに **閲覧者** として共有します。
3. 客先の管理者が、そのスプレッドシートを開いて **ファイル → コピーを作成** します（コピーは客先のドライブに保存され、客先がオーナーになります）。
4. 客先のコピーで、上の **手順2（初期設定の権限確認）・4（Webアプリ公開）・5（毎朝の通知）** をやり直します。トリガー・Webアプリの公開設定はコピーされないためです。新しい打刻用URLを従業員に案内します。
5. 自分のアカウントの元のスプレッドシートは、引っ越し完了後に削除します。

> Googleの仕様で、別の会社（別ドメイン）のアカウントにオーナー権限を直接移すことはできないため、「コピーを作成」で移します。

## 客先のClaude Codeで保守する場合
`CLAUDE.md` に構成と保守の手順をまとめています。客先のリポジトリにこのフォルダ（`roumu-sheets`）と計算ロジック（`roumu/src/lib`）をコピーして開けば、Claude Codeがその前提で作業できます。
[clasp](https://github.com/google/clasp)（Google公式のコマンドラインツール）を使うと、Claude Codeから直接 Apps Script に反映できます（`.clasp.json.example` 参照）。
