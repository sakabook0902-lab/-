# 勤怠・給与計算・労務手続き管理システム（MVP）

従業員10名前後の会社向けに、**打刻 → 勤怠集計 → 給与計算 → 給与明細・賃金台帳 → 労務手続きのタスク化**までを1つにまとめた社内システムです。
「人事労務freee」のような勤怠・給与計算のSaaSの基本機能を自前で持ち、さらに労務手続きの期限管理を自動化します。

提案の背景・SaaSとの比較・導入の進め方は `../docs/roumu-automation-proposal.md` を参照してください。

## できること

| 分野 | 機能 |
|---|---|
| 打刻 | 社員番号＋PINで出勤・退勤・休憩開始・休憩終了（スマホ対応）。勤務場所（五反田／赤坂／リモート）を記録。日付をまたぐ勤務にも対応 |
| 勤怠 | 日次の実働・時間外（1日8時間超＋週40時間超）・深夜（22〜5時）・法定休日労働を自動計算。管理者による修正は操作ログに残る |
| 36協定 | 月45時間（設定可）の80%で注意、超過で警告。月100時間未満・2〜6ヶ月平均80時間の法定上限もチェック |
| 有給休暇 | 入社日から法定の付与日数を自動計算（6ヶ月で10日〜最大20日）、2年で時効、古い付与分から消化。**年5日の取得義務の期限アラート** |
| 給与計算 | 基本給・役職手当・通勤手当・固定残業代（超過分は自動で追加支給）・休日／深夜手当・インセンティブ（歩合給の割増も計算）・欠勤控除 |
| 控除 | 健康保険（40〜64歳は介護保険を含む）・子ども・子育て支援金・厚生年金・雇用保険（法定の端数処理）、源泉所得税（甲欄・電算機計算の特例）、住民税（6月分と7月以降分） |
| 帳票 | 給与明細（印刷・PDF保存）、**法定三帳簿のCSV**（労働者名簿・出勤簿・賃金台帳） |
| 労務手続きの自動化 | 入社登録で資格取得届などの入社手続きタスクを、退職登録で資格喪失届・離職票・源泉徴収票などの退職手続きタスクを期限付きで自動作成。算定基礎届・年度更新・年末調整・法定調書・住民税更新・36協定更新を年次タスクとして自動作成 |
| 随時改定 | 固定的賃金を変更すると記録し、3ヶ月分の給与が確定した時点で**月額変更届の要否（2等級以上の差）を自動判定**してタスク化 |
| 算定基礎 | 4〜6月支給の給与から9月以降の標準報酬月額を試算 |
| 統制 | 管理画面はパスワード保護（Basic認証）。勤怠修正・給与確定／取消・設定変更・CSV出力をすべて操作ログに記録 |

## クラウドに公開する（URLを開くだけで使う）

リポジトリ直下の `render.yaml` を使って [Render](https://render.com) に公開できます（月額 約1,100〜1,300円）。
手順と、客先のアカウントへの引っ越し方法は **`DEPLOY.md`** を参照してください。設定画面の「バックアップ・復元」で、全データを別の環境へ移せます。

## セットアップ・起動（自分のパソコンで試す場合）

```bash
cd roumu
npm install
cp .env.example .env   # ADMIN_PASSWORD を設定
npm run seed           # （任意）架空の従業員3名のデモデータを投入
npm run start:env
```

ブラウザで `http://localhost:3100` を開きます。データは `roumu/data/roumu.db`（SQLite）に保存されます（リポジトリには含めません）。
打刻画面 `http://localhost:3100/punch` だけは管理者パスワードなしで開けるので、従業員にはこのURLを案内します。

テスト（計算ロジック）：

```bash
npm test
```

## 毎月の運用

1. 従業員が `/punch` で打刻
2. 月末に「勤怠」で打刻漏れを確認・修正（ダッシュボードに退勤打刻漏れが出ます）
3. 「給与計算」で対象月を選び、**① 勤怠データから一括計算**
4. インセンティブ・欠勤日数などを各従業員の画面で入力して再計算
5. **③ 一括確定** → 給与明細を印刷・PDF化して配布、賃金台帳CSVを保存
6. 「労務タスク」で期限の近い手続きを処理して「完了」

## ⚠ 本番利用の前に必ず確認すること

1. **料率の確認**：設定画面の「要確認」の項目（健康保険料率・介護保険料率・子ども・子育て支援金率・雇用保険料率）を、協会けんぽ（都道府県支部）・厚生労働省の公式資料で確認してください。初期値は令和8年度の公表情報をもとにした仮の値です。健康保険料率（東京）は公式資料で確認できていません。
2. **源泉所得税の確認**：`src/lib/withholding.js` の計算パラメータを、国税庁「令和8年分 電子計算機等を使用して源泉徴収税額を計算する方法」の別表と照合してください（この環境から国税庁サイトにアクセスできず、原典との照合ができていません）。翌年分（令和9年分）は毎年更新が必要です。
3. **並行稼働**：最低2〜3ヶ月は、既存の方法（社労士・既存ソフト）と結果を突き合わせてから切り替えてください。
4. **ADMIN_PASSWORD の設定**：未設定だと誰でも給与情報を見られる開発モードになります。社外に公開する場合はHTTPS化も必須です。
5. **社労士法の線引き**：本システムは手続きの期限・要否を管理するもので、書類の作成・提出は自社の担当者か顧問社労士が行う前提です。

## MVPで対応していないこと（今後の拡張候補）

- 賞与計算・賞与支払届、年末調整の計算、乙欄・日額表の自動計算
- 時給制（パート・アルバイト）、フレックスタイム制、変形労働時間制、比例付与の有給
- 従業員ごとのログイン（マイページで明細閲覧・有給申請）、承認ワークフロー
- e-Govへの電子申請の連携（届書データの出力）、銀行の総合振込データ（全銀フォーマット）の出力
- freee会計などへの給与仕訳の連携
- マイナンバーの保管（安全管理措置が必要なため、本システムでは保持しない設計）
