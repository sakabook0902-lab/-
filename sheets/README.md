# 反社チェック支援スプレッドシート（GAS版）

会社名（または法人番号）を入力すると、法人番号・本社所在地・代表者・資本金・従業員数・業種・設立年月日・
年商（取得できる企業のみ）を自動で調べてくれるGoogleスプレッドシートです。
サーバーを立てる必要はなく、ブラウザだけで使えます。

## できること・できないこと

- **自動で埋まる項目**：法人番号、本社所在地、代表者、資本金、従業員数、業種、設立年月日
  （経済産業省の無料API「gBizINFO」から取得）
- **条件付きで自動取得できる項目**：年商（売上高）
  → 有価証券報告書の提出義務がある企業（主に上場企業等）のみ、財務情報として自動取得できます（J列）。
  非上場の中小企業は多くの場合データがなく、その際はK列に手動確認結果を入力してください。
- **自動では埋まらない項目**：連絡先（電話番号等）、過去の行政処分の有無
  → これらは無料のAPIには存在しないため、シート上に手動入力欄（L〜M列）を用意しています。
  行政処分は各省庁・都道府県の公表ページ、連絡先はSafeBiz等の商用チェックツールや企業サイトを確認してください。
- **自動で生成されるリンク**（P〜R列）：
  - P列「gBizINFO詳細ページ」：法人番号から生成した、gBizINFO公式サイト上のその企業のページへのリンク
  - Q列「関連ニュースを検索」：会社名でGoogleニュースを検索するリンク（実際の記事本文までは自動取得できないため、クリックして目視確認する形）
  - R列「公式サイトを検索」：会社名でGoogle検索するリンク（公式サイトのURL自体は無料APIにはないため、検索結果から確認する形）

## 同姓・同名の会社を区別する方法（絞り込み検索）

会社名だけでは同名の別会社がヒットすることがあります。対象を確実に絞り込むには次の方法があります。

1. **B列に住所を入力する（おすすめ）**：B列には都道府県名（例：東京都）だけでなく、
   「群馬県前橋市広瀬町3-18-15」のような住所全体を入力できます。まず先頭の都道府県で候補を絞り込み、
   それでも複数社残る場合は、入力した住所とgBizINFO側の本社所在地を突き合わせて自動で1社に確定します
   （丁目・番地の書き方やスペースの有無など多少の表記差は吸収しますが、完全に一致しない場合は確定しません）
2. **法人番号で直接指定する**（最も確実）：対象企業の法人番号が分かっている場合、C列に直接入力し、
   メニュー「この行を法人番号から直接取得」を実行すると、名称・住所のあいまいさなく1社だけを取得できます
   （法人番号は国税庁法人番号公表サイト https://www.houjin-bangou.nta.go.jp/ でも調べられます）

なお、会社名・住所を使っても1社に確定できなかった場合はエラーメッセージが表示され、自動では書き込みません
（誤って別会社の情報を反社チェックの記録に使ってしまうことを防ぐためです）。表示されたメッセージに従い、
住所の表記を見直すか、法人番号で直接指定してください。

## セットアップ手順（5分程度）

1. Googleスプレッドシートを新規作成する（https://sheets.new ）
2. メニューの「拡張機能」→「Apps Script」を開く
3. 開いたエディタの中身をすべて削除し、`antisocial-check-gbizinfo.gs` の内容をすべて貼り付ける
4. 画面上部の保存アイコン（フロッピーの絵）で保存する
5. スプレッドシートのタブに戻り、画面を再読み込み（リロード）する
6. しばらくすると、メニューバーに「反社チェック支援」という項目が追加される
   （初回はGoogleから「このスクリプトを承認しますか」という確認が出るので、許可してください）

## 使い方（自動反映モード・おすすめ）

会社名と住所を入力するだけで、その場で自動的に情報が反映されるモードです。毎回メニューを選ぶ必要はありません。

1. メニュー「反社チェック支援」→「シートの初期設定（見出し作成）」を1回実行する（見出し行と行政処分列のプルダウンが作成されます）
2. メニュー「反社チェック支援」→「gBizINFO APIトークンを設定」を実行し、無料のAPIトークンを貼り付ける
   （トークンの取得方法は下記「APIトークンの取得方法」を参照）
3. メニュー「反社チェック支援」→「**自動反映を有効にする**」を1回実行する
   （初回はGoogleの権限確認画面が出るので許可してください）
4. あとはA列（会社名）とB列（都道府県または住所）の**両方**を入力するだけで、その行のC列以降が自動的に埋まります
   - 例：A2に「株式会社サンプル商事」、B2に「東京都渋谷区渋谷1-2-3」と入力し、B2の入力を確定（Enter/Tab）した瞬間に自動検索が走ります
   - 住所まで入力しておくと、同名の会社が複数あっても住所の突き合わせで自動的に1社へ絞り込まれます
   - それでも1社に確定できない場合は、N列（備考）にエラー内容が表示されます。表示された案内に従って、法人番号での直接指定（下記）を使ってください
5. 年商が自動取得できなかった場合（J列が空欄）、連絡先・行政処分の有無（L〜M列）は、外部で確認したうえで手入力する

自動反映が不要になった場合は、メニュー「反社チェック支援」→「自動反映を無効にする」で止められます。

## 使い方（手動モード）

自動反映を使わず、都度メニューから実行したい場合はこちらです。

1. A列（会社名）に調べたい会社名を入力する。同名の別会社が多そうな場合はB列に都道府県または住所も入力する
2. 調べたい行のセルをクリックして選んだ状態で、メニュー「反社チェック支援」→「この行を会社名で検索」を実行する
   → C列以降に法人番号・所在地・代表者・資本金・従業員数・業種・設立年月日・（取得できれば）年商が自動で入る
3. 法人番号が分かっている場合は、C列に直接入力してから「この行を法人番号から直接取得」を使うとより確実
4. 複数行まとめて調べたい場合は、複数の会社名を入力した範囲を選択してから
   「反社チェック支援」→「選択範囲を一括検索（会社名ベース）」を実行する

## 既にこのスクリプトを使っているシートを更新する場合

1. Apps Scriptエディタの中身を、更新後の `antisocial-check-gbizinfo.gs` の内容にすべて置き換えて保存する
2. メニュー「反社チェック支援」→「シートの初期設定（見出し作成）」をもう一度実行する
   （1行目の見出しがP〜R列まで拡張されます。A〜O列の既存データは消えません）
3. 既にA〜O列まで入力済みの行にP〜R列のリンクを反映したい場合は、B列のセルを一度選び直してEnterを押すか、
   その行を選んでメニュー「この行を会社名で検索」を実行すると、P〜R列も含めて反映されます

## APIトークンの取得方法（無料）

1. https://info.gbiz.go.jp/hojin/APIManual にアクセスする
2. 「利用申請ページへ」から申請する（個人利用の場合はメールアドレスと利用目的のみでOK）
3. 数時間〜数日程度でメールにトークン（英数字の長い文字列）が届く
4. 届いたトークンを、上記「使い方」の手順2でスプレッドシートに設定する

## うまく情報が取得できない場合

- gBizINFOに登録されていない小規模企業などは、項目が空欄のまま返ってくることがあります（正常な動作です）
- 会社名が正式名称と異なると見つからないことがあります（「株式会社」の有無、旧字体など）。正式名称で再検索してみてください
- 住所まで指定しても1社に確定できない場合はN列（備考）にエラーが表示されます。住所の表記（市区町村・番地）を見直すか、法人番号での直接指定を使ってください
- 自動反映が動かない場合は、メニュー「自動反映を有効にする」を実行し直してください（Googleの権限確認が必要な場合があります）
- 「Apps Scriptの実際のレスポンス項目名が想定と異なる場合」の調整方法は、`antisocial-check-gbizinfo.gs` 内のコメントを参照してください
