# 反社チェックシステム（MVP）

社内の与信管理業務における反社会的勢力（反社）チェックを、申請〜自動一次スクリーニング〜外部データ照会結果の記録〜承認〜証跡管理〜再チェックリマインドまで一元管理するための社内システムです。

`docs/antisocial-check-system-proposal.md` の提案（ハイブリッド型：外部データ照会は維持しつつ、業務フローと証跡管理を内製化）を実装したものです。

## できること

1. **チェック依頼登録** — 取引先名称・代表者・所在地等を登録すると、登録済みの自社ブラックリストと自動で名称照合（一次スクリーニング）を実施
2. **外部データ照会結果の記録** — SafeBiz（アリュクス）や官報検索、都道府県公表情報など、外部で確認した結果（シロ／要確認／クロ）と根拠を記録
3. **最終判定・承認** — 与信管理責任者が承認／否認／保留を確定。承認時は次回再チェック期限（1年後）を自動設定
4. **証跡（監査ログ）** — 誰が・いつ・何をしたかをすべての案件で自動記録
5. **再チェックリマインド一覧** — 承認済み案件のうち、再チェック期限が近い／超過したものを一覧表示
6. **ブラックリスト管理** — 自社で過去に取引謝絶・関係解消した先を登録・一覧

## セットアップ・起動

```bash
cd app
npm install
npm start
```

起動後、ブラウザで `http://localhost:3000` を開いてください。データは `app/data/app.db`（SQLite）に保存されます（`.gitignore` によりリポジトリには含めません）。
