# 労務手続きの自動化・勤怠給与システム 導入提案（株式会社ニジ看護転職 向け）

## 0. 前提

| 項目 | 内容 |
|---|---|
| 対象 | 株式会社ニジ看護転職（2024年8月設立、従業員5〜10名程度、拠点：五反田・赤坂＋リモート） |
| 業務委託の範囲 | バックオフィス業務の効率化（第一弾：労務） |
| 想定される特徴 | 有料職業紹介業のため、成約に応じたインセンティブ（歩合給）・固定残業代・拠点またぎの勤務がある。今後採用を増やす段階 |
| 未確認事項 | 現在の勤怠・給与計算の方法、社労士への委託の有無、就業規則・36協定の有無 → ヒアリングで確認 |

## 1. 自動化の対象と効果

| 業務 | 現在（想定） | 自動化後 |
|---|---|---|
| 勤怠集計 | Excel・自己申告を手集計 | 打刻データから時間外・深夜・休日を自動集計。36協定の上限に近づくとアラート |
| 給与計算 | 手計算・Excel | 勤怠から一括計算。固定残業代の超過分、**インセンティブの割増賃金**（未払いになりやすい論点）も自動計算 |
| 給与明細・賃金台帳 | 手作成 | 自動作成（印刷・PDF・CSV） |
| 入退社手続き | 担当者の記憶・経験頼み | 入社／退職を登録すると、必要な届出と期限がタスクとして自動で並ぶ |
| 社会保険の改定 | 見落としがち | 昇給・降給から3ヶ月後に**月額変更届の要否を自動判定**。算定基礎の試算も自動 |
| 有給休暇 | 管理簿がない／手管理 | 付与・残日数・年5日取得義務を自動管理し、期限前にアラート |

## 2. 実現方法の比較

| | A：SaaS導入（人事労務freee等） | B：自社システム（今回作成したMVP） | C：SaaS＋自動化部分のみ自社システム |
|---|---|---|---|
| 初期費用 | 小（設定作業のみ） | 開発済み（MVP）。本番化に向けた調整が必要 | 中 |
| 月額費用 | 従業員数に応じた利用料（プラン・人数で変動、要見積り） | サーバー代のみ（数百〜数千円程度） | SaaS利用料＋サーバー代 |
| 法改正・料率改定への対応 | ベンダーが自動対応 | **毎年、自分たちで更新が必要**（料率・源泉税の計算式など） | SaaS側は自動 |
| 自社の制度への合わせやすさ | 標準機能の範囲内 | インセンティブの計算・アラート・タスクなど自由に作り込める | 自動化部分は自由 |
| 計算ミスの責任 | ベンダーの品質保証あり（ただし最終責任は会社） | 自社（または保守を担う顧問）が負う | 計算はベンダー |
| 向いているケース | 保守の担い手がいない場合 | 顧問が保守まで継続して担う場合 | 給与計算はSaaSに任せ、労務の管理を作り込みたい場合 |

### 推奨

- **顧問（アンカー）が月次の保守まで継続して担う前提なら、Bで進めます。** 料率の改定確認・年1回の源泉税の更新・計算結果の監修を顧問契約に含めることで、SaaS利用料の削減と自社に合った作り込みを両立できます。
- **保守の継続が難しい場合、または検証期間中に計算差異が解消できない場合は、Cに切り替えます。** 給与計算本体はSaaSに任せ、労務タスクの自動化・36協定や有給のアラートなどの管理機能だけを残します。

## 3. 導入スケジュール（案）

| 時期 | 内容 |
|---|---|
| 1〜2週目 | ヒアリング（現状の勤怠・給与の方法、就業規則、固定残業代・インセンティブの規程、社労士の有無）。料率・所定労働時間を設定 |
| 3〜4週目 | 従業員マスタの登録（標準報酬月額・住民税・扶養人数）。打刻の運用開始（従業員への案内） |
| 2〜4ヶ月目 | **並行稼働**：既存の方法と給与計算結果を毎月突き合わせ、差異があれば原因を特定して修正 |
| 5ヶ月目〜 | 本番切替。労務タスク・アラートの運用を定着させる |

## 4. 注意点

1. **社労士法との線引き**：社会保険・労働保険の届出書類の作成・提出を報酬を得て代行できるのは社会保険労務士のみです（社労士法27条）。本システムは「何を・いつまでに」を管理し、提出は自社の担当者または顧問社労士が行う運用とします。
2. **個人情報の管理**：給与・住民税などの個人情報を扱うため、管理者パスワードの設定、HTTPS化、バックアップ、業務委託契約の秘密保持・個人情報条項の確認が必要です。マイナンバーは本システムでは保持しません。
3. **料率・税額の確認**：初期設定の料率は令和8年度の公表情報をもとにした仮の値です。健康保険料率（東京支部）と源泉所得税の計算式は、公式資料（協会けんぽ・国税庁）との照合が済むまで本番利用しないでください。
4. **就業規則との整合**：固定残業代の時間数・インセンティブの支給条件・法定休日の曜日は、就業規則・賃金規程の定めに合わせて設定します。規程がない場合は先に整備が必要です（常時10人以上で作成・届出義務）。
